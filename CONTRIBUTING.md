# Contributing to NexusChat

Thank you for your interest in contributing to NexusChat!

## Getting Started

1. Fork the repository.
2. Clone your fork:
   ```bash
   git clone https://github.com/your-username/nexuschat.git
   cd nexuschat
   ```
3. Create a new branch:
   ```bash
   git checkout -b feature/my-new-feature
   ```

## Development Workflow

1. Ensure dependencies are installed and environment files are properly configured using `.env.example`.
2. Write clean, readable code and keep commits concise and descriptive.
3. Add appropriate tests under `tests/` directories for any new functionality or bug fixes.
4. Verify tests and linting before submitting changes.

## Submitting Pull Requests

- Use the provided Pull Request template.
- Link relevant issues in the PR description.
- Keep pull requests focused on a single topic or feature.

## Code of Conduct

Please be respectful and constructive in all community discussions and reviews.
